Drifty — vehicle appearance inspector

Every car is drawn from cards.json, produced by drifty_tests --dump-corpus-cards. The sprite is the exact PNG the CPU rasterizer emits at the scale the game draws at; overlays are computed from the same derived CarVisual the rasterizer read, so an overlay that disagrees with the pixels is a rasterizer bug, not a drawing error here.
